# sayali1008.github.io

Personal portfolio site for Sayali Moghe — AI & Software Engineer.

**Live:** https://sayali1008.github.io

## Stack

- React 19 + TypeScript
- Vite 6
- CSS Modules

## Local dev

```bash
npm install
npm run dev
```

## Deploy

```bash
npm run build && npm run deploy
```

Deploys the `dist/` folder to the `gh-pages` branch via the [gh-pages](https://github.com/tschaub/gh-pages) package.
